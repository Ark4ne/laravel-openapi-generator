The package ships two skills for coding agents such as Claude Code or Cursor, in
`vendor/ark4ne/laravel-openapi-generator/skills/`. They hold the rules that prevent most mistakes, the reference of
every attribute, configuration key and extension point, and examples the package's own test suite runs.

| Skill | Use it to |
| --- | --- |
| `laravel-openapi-generator` | document endpoints, fix what the generated document gets wrong, write extensions |
| `laravel-openapi-generator-upgrade` | migrate an application from 0.6: procedure, mapping of every 0.6 key, tag, attribute and class, tested ports |

## Install them

Point your agent to the folder of the skill. With Claude Code, link it into the skills of your project:

```bash [Terminal]
mkdir -p .claude/skills
ln -s ../../vendor/ark4ne/laravel-openapi-generator/skills/laravel-openapi-generator .claude/skills/laravel-openapi-generator
```

The skills follow the version of the package installed: update the package, and the skills are updated with it.

## What they contain

- `SKILL.md`: when to use the skill, the rules, the workflow to document an endpoint, a table of symptoms and causes.
- `reference.md`: every attribute and its parameters, every configuration key, every extension point, the commands.
- `recipes.md`: complete examples (CRUD, declared responses and exceptions, requests described by hand, webhooks,
  extensions, JSON:API), each one run by the test suite in OpenAPI 3.0, 3.1 and 3.2.

For the migration from 0.6, see also the [upgrade guide](/laravel-openapi-generator/upgrade).
