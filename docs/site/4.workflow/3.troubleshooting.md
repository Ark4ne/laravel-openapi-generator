---
title: Troubleshooting
description: The usual reasons a route, a response, a body or a property is missing or wrong, and how to fix them.
---

Start with `php artisan openapi:inspect <route>` and `php artisan openapi:generate -v`: the diagnostics usually name
the cause. See [Diagnostics](/laravel-openapi-generator/workflow/diagnostics).

::accordion
:::accordion-item{label="A route is missing from the document"}
It is not matched by `routes.include` (`api/*` by default), or it is excluded: `routes.exclude`, `#[Exclude]`, a
redirect or view route, the fallback route, or an internal route of Laravel or of a package (`routes.internal`).
`php artisan openapi:inspect <route>` tells whether it is in the document. See
[Choose the routes](/laravel-openapi-generator/documenting-endpoints/routes-and-operations#choose-the-routes).
:::
:::accordion-item{label="A response has no schema, or an empty object"}
The action has no return type, or returns an untyped `JsonResponse`. Type the return (`@return` for the details), or
declare `#[Response(type: 'array{…}')]`. `openapi:generate -v` lists these cases.
:::
:::accordion-item{label="A resource is empty, or a property is missing"}
`toArray()` failed on the sampled model: the warning says why. Give the model a factory, `@property` tags or casts, or
give the resource a `#[ResourceFactory]`. See [Sampling](/laravel-openapi-generator/documenting-endpoints/sampling).
:::
:::accordion-item{label="A property should be optional, or should be required"}
A key computed with `when()`, `whenLoaded()` or `mergeWhen()` is optional; a plain value is required. Change the
resource, not the document.
:::
:::accordion-item{label="The request has no body"}
The rules are not in a form request (`$request->validate()` in the controller is not read), or the method is `GET`,
`HEAD` or `DELETE`, whose fields go to the query. Move the rules to a form request, or declare `#[RequestBody]`.
:::
:::accordion-item{label="A list has no pagination"}
The return type does not tell the paginator. Declare
`#[Response(resource: BookResource::class, paginator: LengthAwarePaginator::class)]`.
:::
:::accordion-item{label="The security is wrong"}
Add the middleware to the route, or declare `#[Security('scheme')]`. Declare custom schemes in `security_schemes`. See
[Security & errors](/laravel-openapi-generator/documenting-endpoints/security-and-errors).
:::
:::accordion-item{label="A 3.0 document fails"}
It uses a 3.1 or 3.2 feature (webhooks, `Tag.parent`, `$self`) in a strict document. Set `strict` to `false`, set
`vendor_extensions` to `redoc`, or write another version. See
[OpenAPI version](/laravel-openapi-generator/documents/configuring-a-document#openapi-version).
:::
:::accordion-item{label="Does the generation touch the database?"}
Factories run inside a transaction rolled back at the end, opened on the default connection only, when its driver is in
`sampling.connections`. Models of another connection, or of a driver not listed, are only made, never saved. Set
`sampling.transactions` to `false` to never write.
:::
:::accordion-item{label="Can the package serve the document (Swagger UI, Redoc, Scalar)?"}
No. Write the document where a viewer can read it (a public disk, a static site) and point a dedicated package or a
static viewer to the file. See [Output](/laravel-openapi-generator/documents/output).
:::
:::accordion-item{label="I edited the generated file and my changes are gone"}
Every run rewrites it. Change the code, the attributes or `config/openapi.php`; for a change over the whole document,
write a [pass](/laravel-openapi-generator/extending/passes-and-middlewares).
:::
