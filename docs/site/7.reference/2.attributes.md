---
title: Attributes
description: Every PHP attribute of the generator, where it goes and each of its parameters.
---

All attributes are in `Ark4ne\OpenApi\Attributes`. Those accepted on a controller apply to each of its actions; the
action overrides them. The attributes of a parent class or of a parent method are merged under those of the child.
Types are [PHPDoc types](/laravel-openapi-generator/reference/phpdoc-types). An attribute that cannot be built (an
unknown or wrong argument) is left out with a warning.

## Operation

On a controller or an action. Replaces the metadata given by the PHPDoc and the strategies; on the controller, it
fills only what the action leaves empty.

::field-group
:::field{name="summary" type="?string"}
The summary of the operation.
:::
:::field{name="description" type="?string"}
The description, CommonMark.
:::
:::field{name="operationId" type="?string"}
The operation id, instead of the strategy's.
:::
:::field{name="tags" type="list<string>"}
The tags, replacing those of the strategy. Default `[]`: the strategy's.
:::
:::field{name="deprecated" type="?bool"}
Deprecated or not, over `@deprecated` and `#[\Deprecated]`.
:::
:::field{name="externalDocs" type="?string"}
The URL of the external documentation.
:::
:::field{name="externalDocsDescription" type="?string"}
Its description.
:::
::

## Tag

Repeatable, on a controller or an action. Adds a tag to the operation, and describes it in the document.

::field-group
:::field{name="name" type="string" required}
The name of the tag.
:::
:::field{name="description" type="?string"}
Its description.
:::
:::field{name="parent" type="?string"}
The parent tag: `Tag.parent` in 3.2, `x-tagGroups` before with `vendor_extensions: redoc`.
:::
:::field{name="summary" type="?string"}
A short summary (3.2).
:::
:::field{name="kind" type="?string"}
`nav`, `badge`… (3.2).
:::
:::field{name="externalDocs" type="?string"}
The URL of the external documentation.
:::
:::field{name="externalDocsDescription" type="?string"}
Its description.
:::
::

## Response

Repeatable, on a controller, an action or an exception class. Replaces the response inferred for its status; a declared
success (2xx) leaves out the successes inferred for other statuses. On an exception class, it is the response of the
actions that declare `@throws` with it. See [Responses](/laravel-openapi-generator/documenting-endpoints/responses).

::field-group
:::field{name="status" type="int|string"}
The status, or `'default'`. Default `200`.
:::
:::field{name="description" type="?string"}
The description. Default: the HTTP phrase of the status.
:::
:::field{name="resource" type="?class-string"}
A `JsonResource` or `ResourceCollection` giving the body.
:::
:::field{name="type" type="?string"}
A PHPDoc type giving the body: `array{id: int}`, `list<string>`.
:::
:::field{name="mediaType" type="?string"}
Default `application/json`. With `text/event-stream`, `type` is one event (`itemSchema`, 3.2).
:::
:::field{name="headers" type="array<string, string>"}
Header name → PHPDoc type of its value.
:::
:::field{name="paginator" type="?class-string"}
`LengthAwarePaginator`, `Paginator` or `CursorPaginator`: `resource` paginated, with `links` and `meta`.
:::
:::field{name="summary" type="?string"}
A short summary (3.2).
:::
:::field{name="example" type="mixed"}
An example of the body.
:::
::

Without `resource` nor `type`, the response keeps the body inferred for its status.

## RequestBody

On an action. Gives the body, or describes the body the rules gave. See
[Requests](/laravel-openapi-generator/documenting-endpoints/requests#a-body-without-form-request).

::field-group
:::field{name="type" type="?string"}
A PHPDoc type giving the body.
:::
:::field{name="resource" type="?class-string"}
A resource whose schema is the body (`{data}` for a JSON:API resource).
:::
:::field{name="mediaType" type="?string"}
The media type of the body given by `type` or `resource`. Default `application/json`.
:::
:::field{name="description" type="?string"}
The description of the body.
:::
:::field{name="required" type="?bool"}
`null`: required when the attribute gives the body, unchanged otherwise.
:::
::

## QueryParameter, Header, Cookie

Repeatable, on a controller, a request class or an action. Adds a parameter, or completes the parameter of the same
name and location given by the rules. A parameter left `null` keeps its value. A header is matched whatever the case
of its name.

::field-group
:::field{name="name" type="string" required}
The name of the parameter.
:::
:::field{name="type" type="?string"}
A PHPDoc type. `null`: the schema already described, else `string`.
:::
:::field{name="description" type="?string"}
Its description.
:::
:::field{name="required" type="?bool"}
`null`: unchanged, else not required.
:::
:::field{name="deprecated" type="?bool"}
`#[QueryParameter]` only. `null`: unchanged, else not deprecated.
:::
:::field{name="example" type="mixed"}
An example value.
:::
::

## PathParameter

Repeatable, on an action. Completes a path parameter; it is always required.

::field-group
:::field{name="name" type="string" required}
The name of the parameter, as in the URI.
:::
:::field{name="type" type="?string"}
A PHPDoc type. `null`: the type inferred from the route and the action.
:::
:::field{name="description" type="?string"}
Its description.
:::
:::field{name="example" type="mixed"}
An example value.
:::
::

## Security

Repeatable, on a controller or an action. Each attribute is an alternative requirement; on the action, they replace
those of the class and of the middlewares.

::field-group
:::field{name="scheme" type="string" required}
The name of a security scheme: `sanctum`, `passport`, one of `security_schemes`.
:::
:::field{name="scopes" type="list<string>"}
Its scopes. Default `[]`.
:::
::

## Exclude

On a controller, an action or a closure route. Left out of every document. No parameter.

## Webhook

On a controller or an action. The route is documented under `webhooks` (3.1+, `x-webhooks` before with `redoc`), not
under `paths`. See [Webhooks & callbacks](/laravel-openapi-generator/documenting-endpoints/webhooks-and-callbacks).

::field-group
:::field{name="name" type="?string"}
On an action: the key of the webhook (default: the route name). On a controller: the prefix of the keys of its actions
(`order` + `paid` gives `order.paid`).
:::
::

## Callback

Repeatable, on an action. A request sent back to a URL the client gave.

::field-group
:::field{name="name" type="string" required}
The key of the callback in the operation.
:::
:::field{name="url" type="string" required}
The runtime expression of the URL: `{$request.body#/callback_url}`.
:::
:::field{name="method" type="string"}
The HTTP method. Default `POST`.
:::
:::field{name="webhook" type="?string"}
A webhook whose request and responses the callback reuses.
:::
:::field{name="resource" type="?class-string"}
A resource giving the payload.
:::
:::field{name="type" type="?string"}
A PHPDoc type giving the payload.
:::
:::field{name="mediaType" type="?string"}
The media type of the payload.
:::
:::field{name="description" type="?string"}
The description of the request.
:::
:::field{name="status" type="?int"}
The response expected from the receiver. Default `200`.
:::
::

## ResourceFactory

On a resource whose `toArray()` does not receive a model. Builds the samples it receives. See
[Sampling](/laravel-openapi-generator/documenting-endpoints/sampling#resources-that-do-not-receive-a-model).

::field-group
:::field{name="factory" type="class-string" required}
A model factory class (its `make()` is called), or any class, called through `method` or invoked.
:::
:::field{name="parameters" type="array"}
The attributes given to `make()`, or the arguments given by name to `method` / `__invoke`.
:::
:::field{name="method" type="?string"}
The method of `factory` that builds the sample. Default: `__invoke`.
:::
::

## SchemaName

On a resource or a backed enum. The name of its component; default: the class name without `Resource`.

::field-group
:::field{name="name" type="string" required}
The name of the component.
:::
::
