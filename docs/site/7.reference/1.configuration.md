---
title: Configuration
description: Every key of config/openapi.php, its type and its default.
---

`config/openapi.php` is published with `php artisan vendor:publish --tag=openapi-config` and documented key by key in
the file. It is read when a command runs, never when the application boots: an unknown top-level key or an invalid
value fails the command with the key, the expected value and the received one.

## documents

One entry per document; the key is its name (`--document=v1`, `{document}` in the file name). The published file
declares `v1`. A key a document leaves out takes the default below.

::field-group
:::field{name="openapi" type="string"}
The version written: `3.0.0` to `3.0.4`, `3.1.0` to `3.1.2`, `3.2.0`. Default `3.1.2`.
:::
:::field{name="strict" type="bool"}
`true`: what the version cannot write fails the document. `false`: dropped with a warning. Default `true`.
:::
:::field{name="vendor_extensions" type="none|redoc"}
`redoc`: `x-webhooks` before 3.1, `x-tagGroups` before 3.2. Default `none`.
:::
:::field{name="info" type="array"}
`title`, `version`, `summary` (3.1), `description`, `terms_of_service`, `contact` (`name`, `url`, `email`), `license`
(`name`, `identifier` (3.1), `url`).
:::
:::field{name="self" type="?string"}
The public URI of the document, `$self` (3.2). Default `null`.
:::
:::field{name="external_docs" type="?array"}
`url` and `description`. Default `null`.
:::
:::field{name="servers" type="list<array>"}
The servers of the document; the global `servers` when empty. Default `[]`.
:::
:::field{name="routes.include" type="list<string>|array<string, list<string>>"}
Shell masks on the URI, or a map of masks by `uri`, `name`, `domain`, `middleware`. `null` or `[]`: every route.
Default `['api/*']`.
:::
:::field{name="routes.exclude" type="list<string>|array<string, list<string>>"}
Same form; a route matching one mask is left out. Default `[]`.
:::
:::field{name="routes.ignored_methods" type="list<string>"}
HTTP methods never documented. Default `['HEAD']`.
:::
:::field{name="routes.internal" type="list<string>"}
URI masks of Laravel and common packages, always left out. Default `RouteFilterConfiguration::INTERNAL` (`up`,
`sanctum/csrf-cookie`, `telescope/*`, `horizon/*`, `livewire/*`…).
:::
:::field{name="routes.order" type="registration|path"}
The order of the paths. Default `registration`.
:::
:::field{name="strategies.summary" type="array"}
`by`: `doc` (default), `name`, `uri`, `controller`, or a `SummaryStrategy` class; optional `pattern`, whose first group
is kept.
:::
:::field{name="strategies.tags" type="array"}
`by`: `controller` (default), `uri`, `name`, or a `TagStrategy` class; optional `pattern`. Published:
`/^App\\Http\\Controllers\\(.+)Controller$/`.
:::
:::field{name="strategies.groups" type="?array"}
`null` (default), or like `tags`: the parent tag of each tag. `GroupStrategy` class accepted.
:::
:::field{name="strategies.operation_id" type="array"}
`by`: `name` (default when the key is missing), `action`, `method_path`, `method_name` (published), or an
`OperationIdStrategy` class.
:::
:::field{name="strategies.query" type="array"}
`by`: `all` (default), `last`, `none`, `querystring` (3.2), or a `QueryStrategy` class.
:::
:::field{name="security_schemes" type="array<string, array>"}
Security Scheme Objects by name (OpenAPI field names, camelCase), completing or replacing those of the middlewares.
Default `[]`.
:::
:::field{name="security" type="list<string>"}
Schemes required by default on every operation. Default `[]`.
:::
:::field{name="use_references" type="bool"}
Resources and enums as `components.schemas` referenced by `$ref`. Default `true`.
:::
:::field{name="output" type="array"}
Overrides of the global `output`. Published: `['file' => 'openapi-{document}.json']`.
:::
:::field{name="extensions" type="array<string, mixed>"}
`x-*` extensions of the document root. Default `[]`.
:::
:::field{name="integrations" type="array<string, array>"}
Settings of the integrations for this document, by key; a key no available integration reads is a warning.
`json_api.revision` with `ark4ne/laravel-json-api` 3.x. Default `[]`.
:::
:::field{name="webhooks" type="array"}
Overrides of the global `webhooks`, key by key :since{v="1.3"}. `['paths' => []]`: no payload webhook found by
scanning.
:::
::

## webhooks :since{v="1.3"}

Where the payload webhooks are found: the `JsonResource` classes marked `#[Webhook]`. A document overrides these keys
in its own `webhooks`. See
[Webhooks & callbacks](/laravel-openapi-generator/documenting-endpoints/webhooks-and-callbacks#where-the-classes-are-found).

::field-group
:::field{name="paths" type="list<string>"}
Directories scanned recursively, or PHP files; only the files that mention `Webhook` are read. Published:
`[app_path()]`. Without the key: `[]`.
:::
:::field{name="classes" type="list<class-string>"}
Payload classes listed as given. A class that is not a concrete `JsonResource` marked `#[Webhook]` fails the command.
Default `[]`.
:::
:::field{name="include" type="list<string>"}
Shell masks on the names of the webhooks kept, route webhooks included (`article.*`). Default `[]`: every webhook.
:::
:::field{name="exclude" type="list<string>"}
Shell masks on the names of the webhooks left out, over `include`. Default `[]`.
:::
::

## servers

The default servers of every document. Default: `APP_URL`, described by `APP_NAME`.

::field-group
:::field{name="url" type="string" required}
The URL; parts may be variables: `https://{env}.example.com`.
:::
:::field{name="description" type="?string"}
Its description.
:::
:::field{name="name" type="?string"}
Its name (3.2).
:::
:::field{name="variables" type="array<string, array>"}
By name: `default`, `enum`, `description`.
:::
::

## output

::field-group
:::field{name="disk" type="?string"}
A filesystem disk; `null`: the default disk.
:::
:::field{name="directory" type="string"}
Default `openapi`.
:::
:::field{name="file" type="string"}
`{document}` and `{locale}` are replaced. Default `{document}.json`.
:::
:::field{name="format" type="json|yaml"}
`yaml` needs `symfony/yaml`. Default `json`.
:::
::

## sampling

::field-group
:::field{name="transactions" type="bool"}
Factories `create()` inside a transaction rolled back at the end; `false`: `make()` only. Default `true`.
:::
:::field{name="connections" type="list<string>"}
The drivers a transaction is opened for. Default `['mariadb', 'mysql', 'pgsql', 'sqlite', 'sqlsrv']`.
:::
:::field{name="collection_size" type="int"}
The number of items of a sampled collection. Default `2`.
:::
:::field{name="seed" type="int"}
The seed of the fake values. Default `1`.
:::
:::field{name="examples" type="bool"}
Write the sampled scalars as `example`. Default `true`.
:::
::

## date_formats

PHP date format → OpenAPI format (`date`, `date-time`), for `date_format:` and the sampled values. Default:
`Y-m-d` → `date`, `Y-m-d H:i:s` → `date-time`, `DateTimeInterface::ATOM` → `date-time`.

## middlewares

Middleware name or class → list of `MiddlewareMapper` classes, replacing the built-in mappers of that middleware.
Default `[]`. See [Middleware mappers](/laravel-openapi-generator/extending/passes-and-middlewares#middleware-mappers).

## extensions

Classes added to the registries, built through the container. See [Extending](/laravel-openapi-generator/extending/overview).

::field-group
:::field{name="operation_extractors" type="list<class-string>"}
`OperationExtractor` classes.
:::
:::field{name="request_extractors" type="list<class-string>"}
`RequestExtractor` classes.
:::
:::field{name="rule_mappers" type="list<class-string>"}
`RuleMapper` classes.
:::
:::field{name="response_extractors" type="list<class-string>"}
`ResponseExtractor` classes.
:::
:::field{name="samplers" type="list<class-string>"}
`Sampler` classes.
:::
:::field{name="passes" type="list<class-string>"}
`Pass` classes.
:::
::

## integrations

::field-group
:::field{name="json_api.errors" type="bool"}
Error responses as JSON:API error documents, with `ark4ne/laravel-json-api`. Default `false`.
:::
::

## exceptions

::field-group
:::field{name="read_throws" type="bool"}
Read the `@throws` of the actions. Default `true`.
:::
:::field{name="map" type="array<class-string, int|array>"}
Exception class → status, or `['status' => …, 'description' => …]`. The exception or its closest parent wins.
Default `[]`.
:::
::

## languages

`list<string>`: one document per locale; summaries, descriptions and tags may be translation keys. Default `[]`: one
document in the application locale. See [Translations](/laravel-openapi-generator/documents/translations).
