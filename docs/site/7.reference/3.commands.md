## openapi:generate

Generates every document of the configuration, in each language, validates it and writes it.

```bash [Terminal]
php artisan openapi:generate [--document=*] [--strict] [--dry-run] [--format=] [--stdout]
```

::field-group
:::field{name="--document" type="string, repeatable"}
The documents to generate, by name. Default: all of them. An unknown name is an invalid call.
:::
:::field{name="--strict" type="flag"}
Fails a document on its first warning; the document is not written.
:::
:::field{name="--dry-run" type="flag"}
Generates and validates, writes nothing.
:::
:::field{name="--format" type="json|yaml"}
Instead of the configured format; the extension of the file follows it.
:::
:::field{name="--stdout" type="flag"}
Prints the document instead of writing it. One document and one language; the diagnostics go to the error output.
:::
::

The diagnostics are grouped by route: warnings by default, infos with `-v`, errors only with `-q`.

| Exit code | Meaning |
| --- | --- |
| `0` | every document is written (or valid, with `--dry-run`) |
| `1` | a document has an error, or a warning with `--strict`; it is not written |
| `2` | the configuration or the options are invalid; nothing is generated |

## openapi:inspect

Shows what the generator understood of one route, or of one webhook: its operation after every pass (operation id, summary,
description, tags, deprecation, security, parameters, body, responses) and every diagnostic about it, whatever the
verbosity.

```bash [Terminal]
php artisan openapi:inspect {route} [--document=]
```

::field-group
:::field{name="route" type="string" required}
The name of the route (`books.show`), its URI (`api/books/{book}`, every method), or its method and URI
(`"GET api/books"`). The webhooks of that name (`article.published`) are shown too :since{v="1.3"}.
:::
:::field{name="--document" type="string"}
The document to look in. Default: the first one.
:::
::

| Exit code | Meaning |
| --- | --- |
| `0` | the route is in the document |
| `1` | it is not |
| `2` | the configuration or the document is invalid |

## about

`php artisan about` has an *OpenAPI Generator* section: the version of the package, the names of the documents, and
whether the JSON:API integration is enabled (with the major version of `ark4ne/laravel-json-api`).
