---
title: Webhooks & callbacks
description: Document the requests your application sends, to subscribers and to URLs the client gives.
---

A webhook is a request your application **sends**. It is documented like an endpoint that would receive it: a route
whose action reads the payload, marked `#[Webhook]`. The generator writes it under `webhooks`, never under `paths`.
`#[Callback]` documents a request sent back to a URL the client gave in its own request.

## Describe a webhook

::steps{level="3"}

### Write the payload as a form request

```php [app/Webhooks/OrderPayload.php]
final class OrderPayload extends FormRequest
{
    public function rules(): array
    {
        return [
            'id' => 'required|integer',
            'total' => 'required|numeric',
            'status' => 'required|in:paid,refunded',
        ];
    }
}
```

### Write the action that would receive it

```php [app/Webhooks/OrderWebhooks.php]
use Ark4ne\OpenApi\Attributes\Header;
use Ark4ne\OpenApi\Attributes\Webhook;

#[Webhook('order')]
final class OrderWebhooks
{
    /**
     * An order was paid.
     */
    #[Header(
        'X-Signature',
        type: 'string',
        required: true,
        description: 'HMAC of the body',
    )]
    public function paid(OrderPayload $payload): void {}
}
```

On a controller, the name of `#[Webhook]` is the prefix of the names of its actions: `order` and `paid` give
`order.paid`. On an action, it is the name of the webhook; without name, the route name is used.

### Register a route that never answers

```php [routes/api.php]
Route::middleware(DocumentedOnly::class)->group(function () {
    Route::post('webhooks/orders/paid', [OrderWebhooks::class, 'paid']);
});
```

```php [app/Http/Middleware/DocumentedOnly.php]
final class DocumentedOnly
{
    public function handle(Request $request, Closure $next): never
    {
        abort(404);
    }
}
```

The route exists only to be documented. Like any route, it must match `routes.include` of the document (`api/*` by
default), and a middleware keeps it from answering.

::

::warning
Do not register these routes conditionally (`app()->runningInConsole()`): `php artisan route:cache` runs in the console
too, so they would end up in the route cache and be served.
::

The result, under `webhooks`:

```json
{
  "webhooks": {
    "order.paid": {
      "post": {
        "summary": "An order was paid.",
        "operationId": "order.paid",
        "parameters": [
          { "name": "X-Signature", "in": "header", "required": true, "description": "HMAC of the body", "schema": { "type": "string" } }
        ],
        "requestBody": {
          "required": true,
          "content": {
            "application/json": {
              "schema": {
                "type": "object",
                "required": ["id", "total", "status"],
                "properties": {
                  "id": { "type": "integer" },
                  "total": { "type": "number" },
                  "status": { "type": "string", "enum": ["paid", "refunded"] }
                }
              }
            }
          }
        },
        "responses": { "200": { "description": "OK" } }
      }
    }
  }
}
```

The path parameters and the servers of the route are left out: a webhook has no path. The responses are those the
application expects from the receiver.

## OpenAPI versions

`webhooks` exists from OpenAPI 3.1. In a 3.0 document:

- with `vendor_extensions: redoc`, the webhooks are written as `x-webhooks`;
- otherwise a strict document fails, and a lenient one (`strict: false`) drops them with a warning.

## Callbacks

A callback is a request sent to a URL the client gave, such as a `callback_url` field of its request. Declare it on
the operation that receives that URL, with a runtime expression:

```php [app/Http/Controllers/OrderController.php]
use Ark4ne\OpenApi\Attributes\Callback;

final class OrderController
{
    /**
     * Place an order; the shop calls `callback_url` once it is paid.
     */
    #[Callback(
        'orderPaid',
        url: '{$request.body#/callback_url}',
        webhook: 'order.paid',
    )]
    public function store(StoreOrderRequest $request): OrderResource
    {
        // …
    }
}
```

`webhook` reuses the request and the responses of a webhook. Without it, describe the payload on the attribute:

```php
#[Callback(
    'orderPaid',
    url: '{$request.body#/callback_url}',
    type: 'array{id: int, status: string}',
    description: 'Sent once the order is paid',
    status: 204,
)]
```

| Parameter | Gives |
| --- | --- |
| `name` | the key of the callback in the operation |
| `url` | the runtime expression of the URL |
| `method` | the HTTP method, `POST` by default |
| `webhook` | a webhook whose request and responses are reused |
| `resource`, `type` | the payload, from a resource or a PHPDoc type |
| `mediaType` | the media type of the payload |
| `description` | the description of the request |
| `status` | the response expected from the receiver, `200` by default |

A callback that reuses a missing webhook is left out with a warning.
